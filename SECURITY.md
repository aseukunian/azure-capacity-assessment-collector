# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner privately through an approved channel.

Include the collector version, affected behavior, and reproduction steps. Do not include credentials, access tokens, generated snapshots, tenant IDs, subscription IDs, resource IDs, customer names, or other customer-sensitive data.

## Customer data

The collector writes data only to the local output directory selected by the operator. It does not upload or transmit the generated files. Operators are responsible for reviewing the output and transferring it through channels approved by their organization.
